# Telecom Customer Data Analysis

## 📊 Project Overview

This project focuses on analyzing telecom customer data using Microsoft Excel.

The analysis explores customer information such as city, subscription plan, internet usage, and invoice amount to extract meaningful insights from the data.

## 🎯 Objectives

- Organize and format customer data.
- Calculate basic statistics using Excel functions.
- Sort and filter customer information.
- Create charts to visualize the data.
- Identify key patterns and insights from the analysis.

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning & Formatting
- Data Analysis
- Data Filtering & Sorting
- Data Visualization
- Basic Statistical Functions

## 🔢 Excel Functions Used

- `COUNT` — Count the number of customers.
- `AVERAGE` — Calculate the average invoice amount.
- `MAX` — Find the highest internet usage.
- `MIN` — Find the lowest internet usage.
- `SUM` — Calculate total internet usage.

## Customer Churn Analysis with Python

### Project Overview
This project analyzes telecom customer data to identify patterns associated with customer churn and support data-driven customer retention decisions.

### Objectives
- Inspect and clean customer data.
- Analyze customer churn rates.
- Explore churn patterns by contract type.
- Compare customer tenure and monthly charges between churned and retained customers.
- Summarize key findings and business recommendations.

### Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

### Key Findings
- **Total customers:** 7,043
- **Overall churn rate:** 26.54%
- **Month-to-month contract churn rate:** 42.71%
- **One-year contract churn rate:** 11.27%
- **Two-year contract churn rate:** 2.83%
- **Average tenure of churned customers:** 17.98 months
- **Average tenure of retained customers:** 37.57 months
- **Average monthly charges of churned customers:** 74.44
- **Average monthly charges of retained customers:** 61.27

### Business Recommendations
- Investigate retention opportunities for month-to-month customers.
- Improve engagement during customers' early months.
- Review pricing plans and service usage among customers with higher monthly charges.
- Monitor churn patterns to guide future retention strategies.

### Project Files
- `Customer_Churn_Analysis.ipynb` — Notebook containing the analysis and visualizations.
- `customer_churn_summary.csv` — Summary of key findings.

### Conclusion
The analysis found that churned customers tend to have shorter tenures and higher average monthly charges. Month-to-month customers also have a higher churn rate than customers with longer contracts. These patterns can guide further investigation into customer retention strategies.
