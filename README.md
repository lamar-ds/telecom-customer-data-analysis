# Telecom Customer Data Analysis

## 📊 Project Overview

This project focuses on analyzing telecom customer data using Microsoft Excel.

The analysis explores customer information such as city, subscription plan, internet usage, and invoice amount to extract meaningful insights from the data.

## 🎯 Objectives

- Organize and format customer data.
- Calculate basic statistics using Excel functions.
- Sort and filter customer information.
- Create charts to visualize the data.
- Identify key patterns and insights from the analysis.

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning & Formatting
- Data Analysis
- Data Filtering & Sorting
- Data Visualization
- Basic Statistical Functions

## 🔢 Excel Functions Used

- `COUNT` — Count the number of customers.
- `AVERAGE` — Calculate the average invoice amount.
- `MAX` — Find the highest internet usage.
- `MIN` — Find the lowest internet usage.
- `SUM` — Calculate total internet usage.

## 📈 Key Results

- **Number of customers:** 15
- **Average invoice amount:** 214.67 SAR
- **Highest internet usage:** 210 GB
- **Lowest internet usage:** 30 GB
- **City with the most customers:** Riyadh (4 customers)
- **Total internet usage:** 1,483 GB
- **Most used plan:** Basic plan (6 customers)

## 📊 Data Visualization

The project includes visualizations for:

- Internet usage and invoice amounts.
- Distribution of subscription plans among customers.
